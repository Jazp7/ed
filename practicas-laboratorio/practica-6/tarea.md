# Actividad Práctica en Clase

* Reto: Sistema de Monitoreo e Inventario Hash

Construya un programa en Python que resuelva los siguientes requerimientos utilizando diccionarios:

- Mapeo de registros: Diseñar una estructura de inventario donde las claves sean códigos SKU y los valores sean diccionarios internos con atributos (nombre, precio, existencia).
- Contador de ocurrencias: Procesar una lista de transacciones o registros de eventos y calcular la frecuencia de cada elemento sin usar librerías externas, aplicando .get() con valores por defecto.
- Agrupamiento por categoría: Organizar una lista de elementos en un diccionario donde cada clave sea una categoría y su valor asociado sea una lista con los elementos pertenecientes a ella.
